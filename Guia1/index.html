Tabla de correspondencia

Contenido ya estudiado en el curso Contenido nuevo — función que cumple en el código
Etiquetas HTML Etiquetas semánticas: permiten organizar el contenido de la página mediante elementos como header, nav, main, section, article y footer.
Enlaces Enlaces internos: permiten desplazarse directamente a diferentes secciones de la misma página mediante identificadores.
Listas list-style: none: elimina los marcadores predeterminados de los elementos de una lista.
CSS básico Flexbox: permite organizar y alinear elementos dentro de un contenedor.
CSS básico Grid: permite organizar los elementos en filas y columnas.
Colores y fondos background-color: permite establecer el color de fondo de los diferentes elementos.
Modelo de caja box-sizing: border-box: hace que el padding y el borde se incluyan dentro del ancho y alto establecidos.
Tablas HTML overflow-x: auto: permite desplazar horizontalmente el contenido cuando la tabla supera el espacio disponible.
HTML iframe: permite incrustar contenido externo, como un video de YouTube, dentro de la página.
CSS :hover: permite modificar el estilo de un elemento cuando el cursor se encuentra sobre él.
