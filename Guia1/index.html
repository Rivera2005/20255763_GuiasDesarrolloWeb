Contenido ya estudiado en el curso Contenido nuevo — función que cumple en el código
Estructura del documento: <!DOCTYPE html>, <html lang="es-SV">, <head>, <meta charset>, <meta viewport>, <title> y <body>. Posicionamiento (position: fixed, relative y absolute). Se utiliza para dejar el header fijo en la parte superior, colocar etiquetas como “Nuevo” o “Favorito” sobre las imágenes y posicionar el contenido del hero encima de la imagen de fondo.
Etiquetas semánticas: header, nav, main, section, article y footer. Flexbox (display: flex, align-items, justify-content, gap, flex-direction, flex-wrap y flex: 1). Sirve para acomodar los elementos del header, distribuir los botones del hero, ordenar las tarjetas y organizar el contenido del footer.
Jerarquía de texto: h1, h2, h3, h4, p y span. CSS Grid (display: grid y grid-template-columns). Se usa para crear la cuadrícula de sabores, organizar las tarjetas de negocio, formar el mosaico de fotos de redes sociales y distribuir las columnas del footer.
Listas: ul y li, utilizadas principalmente para el menú de navegación y algunas partes del footer. Media queries (@media). Permiten que la página se adapte a diferentes tamaños de pantalla. Por ejemplo, el menú cambia a formato hamburguesa, las cuadrículas tienen menos columnas y se ajustan los tamaños para tablet y celular.
Enlaces e imágenes: <a href>, <img src> y alt. Unidades relativas y clamp() (rem, %, vh y vw). Hacen que los tamaños y espacios se adapten de forma más fluida al tamaño de la pantalla, por ejemplo en el título principal y en la altura del hero.
Atributos globales: id, class, lang, target y rel. Variables CSS o custom properties (:root). Permiten guardar valores como colores, radios y sombras para reutilizarlos en diferentes partes del CSS sin tener que escribirlos nuevamente y facilitando cambios en el diseño.
Selectores de CSS: selector de tipo, clase, descendiente, combinador >, además de :hover, :focus-visible y :after. backdrop-filter: blur(). Es un efecto visual que genera una especie de fondo esmerilado en el header fijo, haciendo que el contenido que queda detrás se vea desenfocado.
Cascada, herencia y especificidad: reglas que se sobrescriben, herencia de estilos. object-fit: cover y aspect-ratio. Se utilizan para que las imágenes ocupen correctamente el espacio disponible sin deformarse, por ejemplo en imágenes circulares o en contenedores rectangulares.
Propiedades fundamentales: color, background, font-family, font-size, font-weight, text-align, line-height y opacity. scroll-behavior: smooth. Hace que los enlaces internos, como #productos o #tiendas, lleven a la sección correspondiente mediante un desplazamiento suave en lugar de saltar directamente.
Modelo de caja: box-sizing, margin, padding, border, border-radius, width, height y box-shadow. Atributos ARIA: aria-expanded, aria-haspopup, aria-controls, aria-label y role="img". Se utilizan para mejorar la accesibilidad, principalmente para que los lectores de pantalla puedan entender el estado de los menús y elementos que no tienen texto visible.
JavaScript y DOM (querySelector, addEventListener, classList.toggle, foreach y setAttribute). Se encargan de la parte interactiva del menú: abrir y cerrar el menú hamburguesa, mostrar los submenús en pantallas táctiles y cerrar el menú cuando se selecciona un enlace.
